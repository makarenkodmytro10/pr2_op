# Система управління рестораном

Імітаційний прототип системи управління рестораном з можливістю сканування QR-коду меню, оформлення замовлення, підтвердження замовлення офіціантом, позначення готовності страв шеф-кухарем та безконтактної оплати.

## Запуск програми

Найпростіший спосіб запустити програму - використати скрипт `run.sh`:

```bash
./run.sh
```

Скрипт автоматично виконає компіляцію та запуск програми.

### Альтернативний спосіб

Якщо ви хочете запустити програму вручну:

1. Скомпілюйте всі Java файли:
```bash
javac src/*.java
```

2. Запустіть програму:
```bash
java -cp src RestaurantDemo
```

## Структура проєкту

- `src/` - каталог з вихідним кодом
- `run.sh` - скрипт для компіляції та запуску
- `docs/` - каталог з документацією
  - `requirements.md` - вимоги до програми
  - `usecase.puml` - UML-діаграма варіантів використання
  - `class.puml` - UML-діаграма класів
  - `sequence.puml` - UML-діаграма послідовності
  - `state.puml` - UML-діаграма станів
